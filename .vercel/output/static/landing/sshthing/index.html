Quick Questions

Does SSH THING send my data anywhere?

No—no backend for syncing or analytics.

Where are my passwords stored?

OS secure storage (not plain text).

Can I copy from remote sessions?

Yes, via local-only clipboard support.

Works offline?

UI opens offline—SSH needs network access.
