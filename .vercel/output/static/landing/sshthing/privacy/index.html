Privacy Policy for SSH THING (Windows)

Last updated: March 7, 2026

Summary

  • The App does not send your data to developer-controlled servers.
  • The App connects to SSH servers you configure and third-party CDNs for assets.
  • Connection details and settings are stored locally; secrets in Windows credential store.

Information the App Processes

A. Data you enter or save (stored locally)

  • Saved server profiles (nickname, host, port, username, timeout settings)
  • Snippets/actions you create
  • Known host key/trust decisions
  • Local UI preferences (terminal settings)

B. Credentials and secrets (Windows security features)

Passwords and private keys stored using Windows credential store / OS keychain mechanisms (not plain text).

C. SSH session data (in memory during use)

  • Terminal input/output and remote session content
  • Network metadata inherent to SSH connections

D. Clipboard data (optional feature)

May write text to clipboard via OSC 52 sequences (handled locally on your device).

Network Connections

A. SSH connections to your servers

App connects to configured SSH hosts; third-party server operators may log activity per their policies.

B. Loading third-party assets (CDNs)

UI may load assets from third-party providers (Google Fonts, jsDelivr) that receive standard request data.

C. Opening external links

External links open in your default browser; third-party site privacy policies apply.

How the App Uses Data

Only to provide SSH connectivity, save local configuration, store credentials securely, and support clipboard integration.

Data Sharing

Ken Taylor / Lugetech does not receive your data; third parties may receive data as described in Network Connections.

Data Retention

  • Local configuration remains until deleted/uninstalled.
  • Credentials in Windows credential store remain until removed via App/Windows settings.

Security

  • Relies on OS secure storage for secrets.
  • SSH traffic encrypted per SSH protocol.
  • No method of storage/transmission is 100% secure; use trusted hosts and update your system.

Your Choices

  • Choose servers to connect to and information to save.
  • Remove saved data or uninstall the App to delete local files.
  • Manage stored credentials through Windows security settings.

Children’s Privacy

The App is not directed to children under 13; intended for general productivity use.

Changes to This Policy

Last updated date will be revised for changes; material changes may be noted in release notes.
